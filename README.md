# Jeremy Schulze

**AI Systems Engineer · Full-Stack Developer · Open-Source Builder**

I build software at the intersection of AI agents, developer tooling, automation, and infrastructure. My focus is not on demos that only work once, but on systems that are understandable, testable, observable, and maintainable.

My current work spans agent orchestration, LLM tool integration, coding workflows, browser and desktop automation, full-stack web products, and reproducible development environments.

## What I work on

- **AI systems:** multi-agent workflows, tool use, MCP and A2A integrations, stateful orchestration, evaluation, and safety boundaries.
- **Developer tooling:** coding agents, CLI workflows, Git worktrees, repository automation, and local or cloud execution.
- **Full-stack products:** TypeScript, React, Node.js, APIs, payments, and product-oriented frontend development.
- **Infrastructure:** Python, Go, Shell, Docker, CI/CD, Linux and macOS automation, and cloud deployment.
- **Engineering quality:** clear architecture, tests, observability, secure defaults, and documentation that helps others operate the system.
